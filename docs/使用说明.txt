实用工具  v1.0.0
==================================================

【这一版变了什么】

  v1.0 变化（第一个正式版）
  1. 界面可以中英文切换：「设置 → 外观 → 界面语言」选 中文 / English，
     立刻生效，不用重启；下次打开还是上次选的语言。
     窗口标题、托盘菜单、「关于」里的说明都会跟着变。
  2. 新增系统托盘。程序打开后，任务栏右下角会有一个图标：
     左键单击或双击 → 把窗口叫回前台
     右键 → 打开主窗口 / 设置 / 打开数据目录 / 退出
  3. 最小化默认收进托盘，不再占任务栏位置。如果你更习惯最小化就留在任务栏，
     在「设置 → 通用 → 窗口与托盘」里关掉「最小化到托盘」。
  4. 点 × 关闭时第一次会问一次：收进托盘，还是直接退出。选过就照做，不再重复问；
     想改：设置 → 通用 → 关闭窗口时，选「先问我」就恢复成每次都问。
  5. 「关于」页会显示当前版本号、这一版改了什么，还能点「检查更新」。
     有新版本时可以直接下载并安装，也可以打开发布页手动下载。
  6. 版本号重新定为 1.0，作为第一个对外正式版，之前的功能都还在。

  v0.9 变化（内部预览，现已并入 1.0）
  1. 产品更名为「实用工具」，功能与数据完全不变。旧版本的数据可以继续用：
     在「设置 → 数据 → 数据目录 → 更改」里指向原来的 data 文件夹，程序会把
     笔记、待办、设置、图片一起复制过来。
  2. 新增安装程序：下载后双击即可安装，带许可协议页、可选安装目录、
     开始菜单与桌面快捷方式，之后可在「设置 → 应用」里正常卸载。
  3. 安装后不需要再装任何环境。Python 运行时与界面组件都打包在程序里；
     唯一的外部依赖 WebView2 在 Windows 10/11 上随系统预装，安装时会自动检测。
  4. 功能描述统一改成更准确的表述，例如「图片工具：证件照换底、视频转 GIF、
     图片压缩」。
  5. 安装版的数据默认位于 %LOCALAPPDATA%\实用工具\data，卸载只删程序文件，
     数据保留，重装后仍在。

  v2.6 变化
  1. 数据目录可以自己选：「设置 → 数据 → 数据目录」点「更改」，挑一个文件夹，
     重启后生效。切换时会把现有的笔记、待办、设置、图片、备份一起搬过去
     （同名的文件不覆盖；webview 缓存不搬，那个换地方也会重建）。
  2. 图片保存目录也能改，这个不用重启，改完下一次保存就写到新位置。
  3. 两个目录都带「打开」按钮；改过的会在标题旁标「自定义」，
     旁边有「恢复默认」，点一下就能还原。
  4. 默认位置本来就能用：程序旁边的 data 文件夹。如果程序放在
     C:\Program Files 这类写不进去的地方，会自动改用 %APPDATA% 下的目录，
     不用你手动配。

  v2.5 新增
  1. 设置页整个重做：左边一列分类，右边显示这一类的设置，一共 6 类 ——
     外观 / 通用 / 翻译 / AI 接口 / 数据 / 关于。
     分类会记住，下次进设置还是停在上次那一类。
  2. 新增一批设置项（共 11 项）：
        · 界面密度：标准 / 紧凑，紧凑模式一屏能多放几行
        · 界面动效：可以关掉，关掉后切页面、弹窗都不播动画
        · 启动页面：每次打开先进到哪一页，也可以选「上次停留的页面」
        · 启动时最大化：省得每次再点一下最大化
        · 开机自启：随 Windows 启动，不弹黑窗，勾掉即移除
        · 自动翻译延迟：0.4 / 0.6 / 0.9 / 1.5 秒四档
        · 导出目录直达：「数据」里可以直接打开 data\exports
        · 占用空间统计：看得见每个数据文件有多大
        · 备份数据：一键把 data 里的记录复制到 data\backup\时间戳
        · 打开使用说明：直接打开这份文档
        · 复制诊断信息：把版本 / 系统 / WebView2 等信息复制出来，反馈问题用
  3. 这些偏好都会记住，关掉再开还是上次的样子。它们存在 data\ui_prefs.json，
     和翻译、待办那些数据分开放，互不影响；换电脑时一起拷过去就行。

        · AI 接口（新）：接自己的大模型来翻，译文更自然，见下面【AI 翻译接口】

  2. 设置里新增「AI 翻译接口」卡片：填接口地址 + API Key + 模型名，

  v2.3 新增

【怎么用】
  推荐用安装程序：双击「实用工具-3.0.0-安装程序.exe」，按向导走完即可 ——
  选择安装目录（默认装到当前用户，不需要管理员权限）→ 阅读并同意许可协议 →
  完成。装好后开始菜单和桌面会有「实用工具」的快捷方式。
  卸载在「设置 → 应用 → 已安装的应用」里，或开始菜单中的「卸载实用工具」。

  也可以免安装：把「实用工具.exe」放到任意文件夹直接双击运行，
  这时数据存在它旁边的 data 文件夹里，整个文件夹拷走就能换机器。

  首次打开稍慢（约 3-5 秒，要把内置文件解到临时目录），之后快一些。

  打开后左边是侧栏，分三组：
      工作区    概览 / 每日规划 / 翻译 / 记事本 / 待办
      小工具    时间 / 单位换算 / 随机选择 / 数据成图 / 图片工具
      记录      心情日记 / 历史记录 / 收藏夹
      最下面    设置、联网状态

  点侧栏切换功能；右边的顶栏会显示当前页标题，右上角是该页的主要按钮。
  记事本、待办的侧栏项后面有个小数字，是当前条数，为 0 时不显示。
  「每日规划」后面有个小圆点，只有今天已经排了事情的时候才亮。
  任何时候按 Ctrl + K 都能叫出全局搜索，找东西不用先想它存在哪个页面。


【外观】
  右上角「设置 - 外观」里有：
      主题      浅色 / 深色（深色会连系统标题栏一起变深）
      强调色    蓝 / 青 / 琥珀 / 玫红，按钮、选中态、徽标都跟着变
      窗口置顶  打开后窗口始终保持在其他程序前面

  主题和强调色记在本机，下次打开还是上次的样子。


【概览】
  一进来先看这里：
      · 顶部问候 + 今天的日期
      · 五张数字卡：今日待办、今日规划、笔记篇数、翻译记录、收藏条数
        （「今日规划」卡上写着「1/3 已排 2 小时」这种，点进去就是每日规划）
      · 今日待办：今天到期和已逾期的任务，点圆圈直接勾掉
      · 快捷操作：安排今天 / 开始专注 / 添加待办 / 记一笔 /
        单位换算 / 做个选择
      · 最近笔记、最近翻译：各显示最近几条，点一下跳过去继续


【每日规划】
  一天从 6:00 到 24:00 铺成一条竖向时间轴，每格一小时，安排在里面的
  任务就是一块彩色条；两件事时间撞上了，会自动左右并排，不会叠在一起。

  1. 加一件事，三种方法：
        · 点右上角「新建」
        · 直接点时间轴上想要的位置（按半小时对齐，比如点在 9:40 就是 9:30）
        · 点「从待办导入」，把今天没做完、且写了具体时间的待办搬过来
  2. 新建/编辑弹层里填：写什么、几点开始到几点结束、归到哪一类
     （工作 / 生活 / 学习 / 灵感 / 其他，颜色不一样）、备注。
     开始时间改了、结束没改，会自动往后挪 30 分钟。
  3. 点时间块上的圆圈 = 做完了，块会变淡并划掉；点块本身可以再编辑或删除。
  4. 顶部左右箭头翻到前一天 / 后一天，点日期中间回到今天。
     副标题会写「今天 / 昨天 / 明天」。
  5. 右边两块小结：
        · 今天的安排：按时间顺序列全部事项，勾选状态和时间一目了然
        · 分类用时：五类各占多久，横条长度就是比例
  6. 现在这一刻在时间轴上是条红色横线，打开时会自动滚到那附近。
  7. 每条规划都是按天存的，昨天排的不会跑到今天来；只保留最近 400 天。


【时间】★ 新增
  侧栏「小工具 - 时间」，上面三个标签：番茄钟 / 倒数日 / 世界时钟。

  一、番茄钟
  1. 中间一个大圆环，默认 25 分钟；下面一排切换
         专注 25   /   短休 5   /   长休 15
  2. 圆环上面一行可以写「这轮专注做什么」（最多 40 字，可留空）。
  3. 点「开始」，按钮变成「暂停」，再点变「继续」；「重置」回到本轮起点。
  4. 计时按本机时钟校准 —— 中途切到别的页面、把窗口最小化、
     甚至合上盖子过一会儿再回来，剩余时间都是对的，不会越走越慢。
  5. 一轮走完：响一声 + 弹系统通知，自动记一次账并切到 5 分钟短休；
     休息结束再自动切回专注，接着开下一轮就行。
  6. 右边「今天」四格：今天专注（分钟）/ 完成的番茄 / 连续天数 / 累计小时；
     下面「最近完成」把每一轮做了什么、几分钟、几点结束列出来。
     只记专注，不记休息。

  二、倒数日
  1. 右上角「+ 添加」：写标题、选日期、选重复（不重复 / 每年 / 每月），
     还能加一句备注。
  2. 卡片上大字是还剩多少天：「22 天后」；当天显示「今天」；
     已经过去的显示「N 天前」。
  3. 按本机日期算整天数，不掺时分秒，所以不会出现差一天的情况。
     每年/每月重复的会自动找下一次；像 2 月 29 日这种日子，
     在小月会落在当月最后一天，不会算成 3 月。
  4. 最近的排在最前面。卡片右上角：铅笔改、垃圾桶删。

  三、世界时钟
  1. 输入城市名（中文英文都行，如「东京」「Tokyo」「Asia/Tokyo」），
     点「添加」，最多同时看 12 个。
  2. 每张卡：城市名、时:分:秒（秒每秒跳）、当地日期和星期、
     还有一句「比本地快 1 小时 / 比本地慢 13 小时」。
  3. 时差按当地真实时区算，夏令时自动生效 —— 伦敦、纽约这类城市
     的时差会随季节变，这里跟着变，不用自己记。
  4. 下面一排常用城市，点一下直接加到上面；卡片右上角的 × 是删除。
  5. 全部在本机算，不联网。


【心情日记】★ 新增
  1. 左边是日历，一天一格。有记录的那天，格子里就是当天的表情。
  2. 点任意一天 → 右边编辑：从 5 个表情里选一个
     （很差 / 低落 / 一般 / 不错 / 很好），写一句话（最多 120 字），点「保存」。
  3. 「今天」回到本月的今天，左右箭头翻月份；一周从周一开始。
  4. 右侧「这个月」四格：本月记录天数 / 平均心情（5 分制）/
     连续记录天数 / 最好的一天；下面列出最近几条记录，点一下跳回去改。
  5. 同一天再保存就是改；「删除」清掉这一天。一天只存一条。


【数据成图】★ 新增
  两种给数据的方式：直接拖 Excel 进来，或者复制表格粘贴。

  一、拖文件（最省事）
  1. 把 .xlsx / .csv / .tsv / .txt 文件从文件夹直接拖到这个页面，
     框里出现虚线「松手就导入」时松手，马上出图。
  2. 也可以点「导入文件」按钮挑文件，效果一样。
  3. 文件里如果有多张工作表，左上角会出现标签（比如「销售数据 / 区域明细」），
     点一下就换那一张，图和数一起换。
  4. 日期列会自动认成「2026-01-09」这种写法，不会显示成一串序号；
     整列都是文字（备注、说明）的不会当成一组数据画进去。
  5. 行数多的时候只画前 60 行（再多图就看不清了），会提示一句。
  6. 注意：只认 .xlsx，老版的 .xls 请在 Excel 里「另存为」成 .xlsx 或 CSV；
     CSV 的中文编码（UTF-8 / GBK）会自动识别。

  二、粘贴表格
  1. 从 Excel / WPS / 网页表格里框选两列或三列，Ctrl+C、Ctrl+V 到左边框里。
     第一列是标签（月份、人名…），后面每列一组数字，最多认三组；
     表头那一行会被当成系列名。
  2. 数字带千分位、货币符号也能认。

  三、出图
  1. 点「生成图表」，右边立刻出图；右上三个按钮切换
         柱状  /  折线  /  环形
  2. 鼠标停在柱子或数据点上能看到具体数值；标题下面一行写着
     「几行 · 合计多少 · 最高的是哪个」。
  3. 点「复制图片」，图会以图片形式进剪贴板，可直接粘到微信、Word、PPT。
  4. 「填入示例」看看格式长什么样，「清空」清掉重来。
     数据和图都会存下来，下次打开还是上次那张。
  5. 标签太长或太多会自动截短、隔几个显示一个，不会糊成一团。


【图片工具】★ 新增
  侧栏「小工具 - 图片工具」，进来后上方有三个页签：
        证件照  /  视频转 GIF  /  压缩图片

  一、证件照
  1. 把照片拖进左边的框，或者点「选择照片」。
  2. 右边选规格，六种常用尺寸，都是 300 dpi：
          一寸 25×35 mm      小一寸 22×32 mm
          二寸 35×49 mm      大一寸 33×48 mm
          签证 35×45 mm      美签 51×51 mm
  3. 选底色：白底 / 蓝底（证件照标准蓝）/ 红底 / 灰底。
     选「原」就保留原来的背景，只做裁剪。
     · 背景越干净（一面白墙、一块纯色布）换得越准；
       背景里有人、有家具，换完会留一圈原来的颜色。
  4. 照片位置：在照片上按住拖动，滚轮缩放（也可以拉「大小」滑块），
     点「复位」回到居中。
  5. 「换底强度」一般不用动（默认 34）。背景花、换不干净就往上调；
     调到很高会咬到浅色衣服或脸红，往下调一点就好。
  6. 点「保存」出一张 PNG；「复制」直接进剪贴板，能贴到报名系统里。

  二、视频转 GIF
  1. 拖入 mp4 / webm / mov（手机拍的也行），左边能看到画面。
  2. 拉「起点」和「时长」，时长最多 10 秒，默认 3 秒。
     动图越短越清楚，10 秒的动图会比较大。
  3. 帧率选 8 / 10 / 15，宽度选 240 / 320 / 480。
     宽度越大越清楚，文件也越大；做表情包 240 或 320 就够。
  4. 点「生成 GIF」，下面出现进度条，转完能直接预览、看到文件多大。
  5. 点「保存」存成 .gif。转出来的动图是无限循环的。

  三、压缩图片
  1. 拖入图片（jpg / png / webp / bmp 都行）。
  2. 选目标大小：50 KB / 100 KB / 200 KB / 500 KB / 1 MB，
     或者直接在下面那个框里填数字（报名系统常写「200KB 以内」，就填 200）。
  3. 选格式：JPEG 最通用，WebP 同画质下更小（但有些老系统不认）。
  4. 「最长边不超过」：不确定就选「原尺寸」；
     要发微信、贴网页，选 1920 或 1280 更省地方。
  5. 点「开始压缩」，下面会列出原始大小、压缩后大小、尺寸比例和画质。
     它优先保画质，实在压不到目标才自动缩尺寸，
     所以有时候「尺寸」那一行会显示 76% 之类。
  6. 点「保存」，文件名会自动带上目标大小，比如「压缩-照片-200KB.jpg」。

  说明：三样东西都在本机算，不联网、不上传；保存的文件在
        data\exports\ 里，点保存提示后面的「打开文件夹」直接打开。


【全局搜索】★ 新增
  1. 按 Ctrl + K，或点右上角那个「搜索 / Ctrl K」，随时叫出来。
  2. 一个框同时搜六处：笔记（标题和正文）、待办、每日规划、
     倒数日、翻译历史、心情日记。
  3. 结果按类型分组，命中的关键词会高亮。
     ↑ ↓ 选，回车跳过去，Esc 关掉。
  4. 跳到笔记 / 待办 / 规划时，会自动定位到那一条并闪一下。


【文本翻译】
  1. 左边输入或粘贴文字，按 Ctrl + Enter 或点右下角「翻译」。
  2. 顶部可切换 原文语言 / 译文语言；原文选「自动检测」时会自动识别语种，
     右边译文区顶部会显示识别结果（比如「英语」）。
  3. 点中间的 ⇄ 一键互换语言，并把译文当新原文接着译。
  4. 译文区右下角：复制、朗读、收藏、存为笔记。
  5. 打开「自动翻译」后，停下打字约 1 秒自动翻。

  快捷键
      Ctrl + Enter     立即翻译
      Esc              关闭弹层 / 让输入框失焦


【翻译通道】
  一共 6 条通道，默认「智能选择」按下面的顺序自动兜底，某条不通就换下一条：

      微软必应  ->  网易有道  ->  MyMemory  ->  Google  ->  腾讯交互翻译

      另有「AI 接口」一条，配好才用，见下面【AI 翻译接口】。

  想固定用某一条，在「设置 - 翻译 - 默认通道」里指定，
  再点下面的「检测通道可用性」，看当前网络下哪条最快：
      结果显示成「4/6 可用 · 微软必应、网易有道…」，鼠标悬停能看到每一条的
      具体耗时，或者失败的原文原因（比如被限流、连不上）。
  （Google 在国内网络通常不可用，只作备用；
    腾讯交互翻译不用注册、不用填 Key，装上就能用，中文短句又快又顺。）


【AI 翻译接口】★ 新增
  用大模型来翻译，长句、口语、专业内容比传统机翻通顺得多。
  这是可选项，不配的话上面 5 条免费通道照常用，不影响任何现有功能。

  1. 在「设置 - AI 翻译接口」里填三样：
        服务商      点一下 DeepSeek / 通义千问 / 智谱 GLM / Kimi / 硅基流动 /
                    OpenAI / 本地 Ollama，会自动填好下面两行
        接口地址    形如 https://api.deepseek.com/v1
                    填到 /v1 就行，末尾的 /chat/completions 程序自己补
        API Key     去服务商后台申请，粘进来
        模型        预设一般已经填好，想换别的型号直接改
  2. 点「保存并测试」，几秒后提示「AI 接口已连通」，并显示耗时和一句示例译文，
     卡片右上角的标签会从「未配置」变成「已就绪」。
  3. 到翻译页右上角「翻译通道」里选「AI 接口」，之后就都走大模型。
     没配就选了它，译文区会提示「还没填 API Key，先去设置里填一个」。
  4. 常见服务商（都有免费额度，或者便宜到可以忽略）：
        DeepSeek      api.deepseek.com
        通义千问      dashscope.aliyuncs.com（兼容模式）
        智谱 GLM      open.bigmodel.cn（glm-4-flash 免费）
        Kimi          api.moonshot.cn
        硅基流动      api.siliconflow.cn（注册送额度）
        本地 Ollama   http://127.0.0.1:11434/v1（不联网、不花钱，得先装 Ollama）
        其他         任何 OpenAI 兼容接口都能填，地址填到 /v1 即可
  5. Key 只存在本机的 data\settings.json 里，不会上传到别处。
     换电脑要重新填；不想用了点「清空」。
  6. 这个配置同时用于待办的智能识别，不用在两个地方各填一遍。


【记事本】

  2. 内容边写边存，不用点保存，底部会显示「已保存 时:分」。
  3. 标题取第一行文字，自动生成，不用手动起名。
  4. 编辑区上方工具：
        时间      在光标处插入当前日期时间
        分类      给这篇笔记选个分类（现在是哪类，按钮上就写着哪类）
        复制      复制这篇笔记全文
        置顶      钉在列表最上面
        翻译      把这篇笔记送去翻译页
        删除      弹确认框，确认后才删
  5. 分类
        · 搜索框下面一排标签：全部 / 工作 / 生活 / 学习 / 灵感 / 其他，
          每个后面带条数，点一下只看这一类。
        · 列表里每篇笔记标题下面有个小色点 + 分类名。
        · 新建时会自动归到当前选中的分类，省得再改一次。
        · 已经有的笔记：打开它，点上面「分类」按钮改；选「不分类」就移出分类。
  6. 列表顶部可搜索，标题和正文都能搜到；搜索和分类可以一起用。
  7. 左下角显示「几篇 / 多少字」。


【待办】
  一句话就能建任务，识别中文时间说法：
      明天下午3点提醒我取快递 #生活
      下周三 10 点 交周报
      每周一 9:00 站会
      3 天后 复查牙齿

  1. 在输入框敲上面这种句子，下方会先显示「识别为：明天 15:00 · #生活」，
     这时按回车或点「添加」就建成。
  2. 自己选时间：输入框右边有个「选时间」按钮
        · 弹出面板：今天 / 明天 / 后天 / 下周一 四个快捷日期，
          下面一排常用时刻（9:00、12:00、14:00……），
          再往下可以手填具体日期和时间。
        · 选完按钮上会显示「明天 14:00」，建出来的任务就是这个时间。
        · 手动选的比句子里识别的优先 —— 句子里说了「明天3点」，
          你在面板里选了后天 14:00，那就以后天 14:00 为准。
        · 右侧「清除」把选择取消掉。
  3. 也可以点任务右侧的编辑按钮，在弹层里改 标题 / 日期 / 时间 /
     提醒提前多久（5 分钟 / 15 分钟 / 30 分钟 / 1 小时 / 1 天 / 不提醒）/
     重复（不重复、每天、每周、每月、每年）/ 优先级 / 标签 / 备注。
  4. 上方三个标签页：今日、全部、已完成；右边下拉可按标签筛。
  5. 列表会分组显示，每组标题后面带条数：
        今日  ->  已逾期 / 上午 / 下午 / 晚上 / 未定时间
        全部  ->  按日期分组，过期的那组标红
     所以「明天要做的事」和「下周要做的事」一眼能分开。
  6. 到点会弹 Windows 系统通知（前提是「设置 - 提醒」里开着提醒）。
     当天已过时间但还没做的任务不算逾期，只有过了当天的才算。


【单位换算】
  1. 上方一排分类：长度、重量、面积、体积、温度、速度、数据存储、汇率。
  2. 填数值、选源单位和目标单位，结果实时显示，点 ⇄ 互换上下单位。
  3. 温度按换算公式算，不是简单乘系数；汇率按最近一次更新的汇率折算。
  4. 下面的「1 米 约等于」对照表，把同一分类里其他单位一次列出来，
     点任意一行就复制那个数值。
  5. 汇率页有「更新汇率」按钮，成功后显示来源和更新时间。
  6. 每次换算会记在卡片下方「上次换算」一行里。


【随机选择】
  两种玩法，顶部按钮切换，选过哪种下次打开还是那种：

  · 转盘
      1. 候选项会均分成扇区，颜色自动配，不用自己调。
      2. 点中间的「开始转动」或下面的按钮，转盘转 4-6 圈慢慢停，
         指针指到哪块就是哪块，停下的那块会加白边高亮。
      3. 要是只有 2-8 个候选项，扇区里会直接写名字；太多就只留颜色。
      4. 结果自动进「抽取历史」，和滚动模式共用一份。

  · 滚动（原来的方式）
      点「随机选择」，结果区快速滚一遍再停下。

  候选项在左边加，回车确认，一次一个。
  候选和结果自动保存，关掉程序下次还在。


【历史记录 / 收藏夹】
  · 历史记录：所有翻译过的原文和译文，可搜索，可复制、朗读、
    重新翻译、收藏、删除；右上角可一键清空。
  · 收藏夹：只显示收藏过的记录，条数会显示在侧栏徽标上。
  · 保留条数在「设置 - 翻译 - 历史保留条数」里调（默认 300）。


【设置】
  左边是分类，右边是对应的设置，点一下左边就切过去。六类：

  外观
      界面语言    中文 / English，切换后立即生效，重启也记得
      明暗        浅色 / 深色
      强调色      蓝 / 青 / 琥珀 / 玫瑰，影响按钮和选中高亮
      界面密度    标准 / 紧凑，紧凑模式行距变小、一屏多放几行
      界面动效    关掉后切页面、弹窗、提示都不播动画（老电脑更跟手）
      窗口置顶    让窗口一直在最前面

  通用
      启动页面    下次打开先进哪一页；选「上次停留的页面」就接着上次看
      启动时最大化 打开就是最大化窗口
      开机自启    随 Windows 启动，不弹黑窗；不想要了关掉开关即移除
      启用提醒    待办到点弹系统通知
      测试通知    发一条试试，确认通知没被系统拦住

  翻译
      默认通道    智能选择会自动切换可用的通道
      默认译文语言 翻译页初始的目标语言
      历史保留条数 超出后自动清理最早的记录（收藏的不会删）
      启用自动翻译 输入框停手后自动请求译文
      停手多久   0.4 / 0.6 / 0.9 / 1.5 秒，默认 0.9 秒
      检测通道可用性 把 6 条通道逐个试一遍，看当前网络哪条能用

  AI 接口
      服务商预设、接口地址、API Key、模型、保存并测试、清空（详见上一节）

  数据
      数据目录    当前数据存在哪；「更改」换位置（重启生效），「打开」直达
      图片保存目录 证件照 / GIF / 压缩图存这里；「更改」立即生效，「打开」直达
      占用空间    每个数据文件多大，点「刷新」重新统计
      清空翻译历史 收藏的会保留
      恢复默认设置 只重置设置，不删笔记和待办
      备份数据    把 data 里的记录复制一份到 data\backup\时间戳

  关于
      版本号、打开使用说明、复制诊断信息（版本 / 系统 / Python / WebView2 /
      数据目录 / 占用 / 通道 / AI 状态），反馈问题时连同截图一起发过来就行。


【数据存在哪】
  全部在本机，不上传。安装版默认放在当前用户目录，免安装版放在程序旁边：

      安装版      %LOCALAPPDATA%\实用工具\data\
      免安装版    <程序所在的文件夹>\data\

  位置可以在「设置 → 数据 → 数据目录」里改到别处，例如：

      settings.json            设置
      history.json             翻译历史
      notes.json               笔记正文
      todo_data.json           待办
      random_picker_data.json  随机选择的候选
      currency_rates.json      上次取到的汇率
      last_conversion.json     上次换算
      plan_data.json           每日规划（按日期存）
      note_meta.json           笔记分类
      focus_log.json           番茄钟的每一轮记录 ★ 新增
      countdown_data.json      倒数日 ★ 新增
      mood_diary.json          心情日记（一天一条）★ 新增
      chart_data.json          上次粘的数据和图
      ui_prefs.json            界面偏好：主题色、界面密度、动效、启动页面 ★ 新增
      exports\                 图片工具存下来的证件照 / 动图 / 压缩图
      backup\                  设置里点「备份数据」时存的副本，按时间戳分文件夹 ★ 新增
      webview\                 界面缓存：主题/强调色偏好、世界时钟的城市列表
                               （删掉只会恢复默认外观、丢城市列表，
                                 上面那些数据不受影响）

  备份：直接整个复制 data 文件夹即可；也可以点「设置 - 数据 - 备份数据」，
        程序会把所有 json 复制到 data\backup\时间戳，不动原文件。
  换电脑：exe 和 data 文件夹一起拷过去，位置相对关系不变就能用。

【常见问题】
  启动慢 / 没反应
      首次启动要解压内置文件，等 3-5 秒；若始终不出窗口，
      看 data\startup-error.log 里有没有报错信息。

  图标还是旧的
      Windows 图标有缓存。先关掉程序，右键桌面空白处刷新；
      还不变就注销重登，或者把快捷方式删了重新发送到桌面。

  转盘点了不转
      只有在「转盘」模式下才有转动按钮，而且至少要 2 个候选项。
      看看左上角模式是不是切到了「滚动」。

  规划里点不出新建
      时间轴上点一下就是新建，但点在已有的时间块上是编辑那一块。
      想加事情，点空白处，或者用右上角「新建」。

  通知不弹
      先在「设置 - 通用 - 测试通知」发一条试试。

  开机自启没生效
      到「设置 - 通用 - 开机自启」看一眼开关是不是开着。
      它是往当前用户的注册表 Run 项里写一条启动命令，不需要管理员权限；
      如果装完程序后把 exe 挪了位置，关掉再打开一次开关即可重新登记。

  设置项找不到了
      v2.5 起设置分成六类，在左边（窄窗口时在顶部）点分类切换。
      上次停在哪个分类会被记住，下次进来还是那一页。
      还不行就去 Windows「设置 - 系统 - 通知」里，确认允许本程序通知。

  番茄钟 / 倒数日准不准
      都按这台电脑自己的时钟和日期算，跟网络无关：
      番茄钟记的是「结束时刻 - 现在」，所以切页面、最小化、休眠都不会走偏；
      倒数日按本机日期算整天数，不掺时分秒。
      真觉得时间不对，先去 Windows 设置里同步一下系统时间。

  世界时钟时差不对
      时差是按各个城市的真实时区算的，夏令时期间会差一小时 ——
      这是对的，不是算错。想加别的城市，直接打城市名或 Asia/Tokyo 这种时区名。

  粘了表格不出图
      至少要有两列：第一列文字标签，第二列数字。
      标签列别留空行，数字列别混进「约」「万」这类字，
      认不出来的行会被跳过。看不懂格式就点「填入示例」对照一下。

  拖 Excel 进去没反应
      · 老版 .xls（含 .et）认不了，在 Excel 里另存为 .xlsx 或 CSV 再来。
      · 文件里有多张表时，默认用第一张有数据的；想换点左上角的工作表标签。
      · 整列都是文字（没有数字）不会画进图里，至少得有一列数字。
      · 表格必须放在第一张工作表的前几列，中间别夹空行空列。

  复制图片粘不出来
      点「复制图片」后会有提示。个别聊天软件只接受文件，
      这种情况可以先粘到「画图」里再另存。

  证件照换底色不干净
      换底是按「和背景色接近、并且跟边缘连在一起」来判断的，
      所以背景越纯越好：一面白墙、一块纯色布最理想。
      · 背景里有人、有家具、有花纹，会留一圈原来的颜色，调高「换底强度」能多换一点。
      · 脸或浅色衣服被吃掉了，就把强度往回调。强度拉满也不会把整张脸吃掉，
        最多换到轮廓边缘。
      · 头发边缘有一圈淡色是正常的，缩到一寸大小基本看不出来。

  视频转 GIF 黑屏或转不动
      · 先确认左边能正常播放这个视频；放不出来说明格式不被支持，
        用 mp4（H.264）最稳。
      · 时长拉到 10 秒、宽度选 480 会很慢，也会生成很大的文件，
        做表情包 240 或 320 宽、2-3 秒就够。
      · 有些视频没有内置索引（比如网页录屏直接录的 webm），
        起点可能对得不太准，但画面和时长没问题。

  压缩后比原图还大
      原图本来就很小的时候会出现。它只保证「不超过你填的目标」，
      不会主动把文件做大；如果原图已经比目标小，会直接按最高画质输出。

  图片工具存到哪了
      data\exports\ 文件夹。保存后点提示后面的「打开文件夹」可以直接打开。

  翻译失败
      多半是网络或通道被限流。到「设置 - 翻译」点「检测通道可用性」，
      换一条能用的通道；「智能选择」会自动兜底。
      经常翻长句、口语的话，配一个 AI 接口更省心（设置 - AI 翻译接口），
      配好后在翻译页把通道选成「AI 接口」就行。

  AI 接口测试失败
      · 提示「Key 不对或已失效」：去服务商后台重新复制一遍，注意别带空格
      · 提示「接口地址不对…（404）」：地址要填到 /v1，
        比如 https://api.deepseek.com/v1，末尾的 /chat/completions 程序自己补
      · 提示「连不上」：本机网络到不了那个域名，换国内服务商，
        或者用「本地 Ollama」这条路（需要先装 Ollama 并拉一个模型）
      · 提示「余额不足 / 额度用完」：去服务商后台充值或换一个免费的模型

  窗口太小 / 位置不合适
      窗口最小 1000×660，可以自由拉伸；关掉时会记住大小。

  想彻底重来
      「设置 - 数据 - 恢复默认设置」，或者退出程序后删掉 data 文件夹
      （会连同笔记、待办、规划一起清空，先备份）。
