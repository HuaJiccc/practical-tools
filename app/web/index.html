                            怎么填

                            三个常见情况，照抄就行

                            任意 OpenAI 兼容接口地址填到 /v1，模型填服务商文档里的名字（如 deepseek-chat、qwen-plus、glm-4-flash）。
                            本地 Ollama地址 http://127.0.0.1:11434/v1，Key 随便填 ollama，模型填本地已拉取的（如 qwen2.5）。不联网、不花钱。
                            报错了怎么看401 / 403 是 Key 不对或没权限；404 多半是地址少了 /v1；429 是额度用完或请求太频繁。
